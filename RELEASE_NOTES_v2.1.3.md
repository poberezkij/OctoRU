# OctoRU v2.1.3

## Что нового

- Исправлен блокер `release:check` в проверке словаря:
  - конфликты регистров для пар `Watching/watching` и `Forks/forks` переведены в allowlist `validate-dictionary`, чтобы сохранить корректные морфологические формы.
- Улучшена стабильность fallback-перевода в рантайме:
  - `translationsCI` больше не перезаписывает ранее добавленное базовое значение при конфликте регистра.
- Улучшен релизный пайплайн:
  - добавлен `version:check` для контроля синхронизации версии между `package.json` и `manifest.json`;
  - `release:zip` теперь формирует имя архива автоматически по текущей версии (`dist/OctoRU-v<version>.zip`) и не содержит хардкод.

## Технически

- Версия расширения: `2.1.3`
- Версия npm-пакета: `2.1.3`
- Новый релизный артефакт: `dist/OctoRU-v2.1.3.zip`
