# OctoRU v2.1.5

## Что нового

- Добавлен e2e smoke по ключевым публичным страницам GitHub (5 страниц) с проверкой DOM-ready селекторов.
- Внедрён CI workflow (`.github/workflows/ci.yml`):
  - установка зависимостей;
  - установка Playwright Chromium;
  - запуск `npm run release:check`.
- Улучшен релизный workflow по тегу:
  - добавлены шаги установки зависимостей, браузера Playwright и `release:check` перед публикацией.
- Сбор непереведённых строк переведён на агрегированный отчёт:
  - частота появления (`count`);
  - контекст: `section`, `source`, `url`, `selector`;
  - обратная совместимость со старым списком сохранена.
- Обновлён UI настроек для раздела непереведённых строк:
  - отображается частотный отчёт с контекстом;
  - отдельные кнопки для копирования JSON-шаблона и полного отчёта.
- Добавлена команда релиз-подготовки `release:prepare`:
  - bump версии (`major|minor|patch` или явная версия),
  - автосоздание файла `RELEASE_NOTES_vX.Y.Z.md`,
  - запуск `release:check` и сборка `release:zip`.

## Технически

- Версия расширения: `2.1.5`
- Версия npm-пакета: `2.1.5`
- Релизный артефакт: `dist/OctoRU-v2.1.5.zip`
