# OctoRU v2.1.7

## Что нового

- Исправлен отчёт о непереведённых строках: корректные фильтры, счётчики и экспорт.
- Расширено покрытие интерфейса GitHub для страниц репозиториев, Issues, Pull Requests и Settings.
- Ускорена обработка динамического DOM: вложенные обновления объединяются, неактуальные observer-ы освобождаются.
- Встроенный fallback-словарь теперь генерируется из единого источника и проверяется на рассинхронизацию.
- Удалены спорные переводы пользовательского контента; `README` и технические обозначения сохраняются корректно.
